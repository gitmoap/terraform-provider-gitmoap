# gitmoap_service_account_token (Ephemeral Resource)

A short-lived token for a service account, minted when Terraform opens it and revoked when Terraform is done with it, so it's never in the plan or the state (Terraform 1.10 and later). Use it where a token is needed for the length of a run: to configure a provider, or a write-only argument read during it. A token that has to outlive the run, like one a pipeline uses, is `gitmoap_service_account_token`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "platform" {
  full_path = "acme/platform"
}

resource "gitmoap_group_service_account" "ci" {
  group_id     = data.gitmoap_group_by_path.platform.group_id
  name         = "ci"
  access_level = "developer"
}

# A token that only reads groups, for a provider configuration used during this run. Terraform
# revokes it when it's done, and never stores it.
ephemeral "gitmoap_service_account_token" "reader" {
  sa_id  = gitmoap_group_service_account.ci.service_account_id
  name   = "terraform-run"
  scopes = ["group:read"]
}

provider "gitmoap" {
  alias = "reader"
  token = ephemeral.gitmoap_service_account_token.reader.token
}

data "gitmoap_group_by_path" "acme_as_reader" {
  provider  = gitmoap.reader
  full_path = "acme"
}
```

### A short-lived token for one run

An ephemeral token, minted when Terraform opens it and revoked when it's done, configures a second
gitmoap provider that only reads groups: the rest of the run can't write anything through it, and
the token is never in the plan or the state (Terraform 1.10 and later). The service account it acts
as exists already, since Terraform can't configure a provider with what the same run creates.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

# The reader service account, found by its name.
data "gitmoap_group_service_accounts" "acme" {
  group_id = data.gitmoap_group_by_path.acme.group_id
}

locals {
  reader_id = one([for account in data.gitmoap_group_service_accounts.acme.items : account.service_account_id if account.name == "reader"])
}

ephemeral "gitmoap_service_account_token" "reader" {
  sa_id  = local.reader_id
  name   = "terraform-run"
  scopes = ["group:read"]
}

provider "gitmoap" {
  alias = "reader"
  token = ephemeral.gitmoap_service_account_token.reader.token
}

# Read through the reader's token.
data "gitmoap_group" "acme" {
  provider = gitmoap.reader
  group_id = data.gitmoap_group_by_path.acme.group_id
}

output "group_name" {
  value = data.gitmoap_group.acme.group_name
}
```

## Schema

### Required

- `name` (String) What the token is for, as its list of tokens shows it.
- `sa_id` (String) The service account the token acts as.
- `scopes` (List of String) The scopes the token carries, such as `repo:read`.

### Optional

- `expires_in_days` (Number) Days until the token expires, should revoking it fail. Defaults to 1.
- `resource` (Attributes) Restricts the token to one group subtree or repository. (see [below for nested schema](#nestedatt--resource))

### Read-Only

- `expires_at` (String) When the token expires, if Terraform doesn't revoke it first.
- `token` (String, Sensitive) The token.
- `token_id` (String) The token's id.
