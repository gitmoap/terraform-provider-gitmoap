# gitmoap_catalog_service (Resource)

Adds a service to the catalog, declared in this group and bound to one or more repository paths (an external service is not built here and binds none). Maintainers and above on the group may declare one; naming a group as owner needs the same standing on that group, naming a team needs authority over the team, and every bound repository must be one you maintain. The slug must be unique in the organization, and the number of services is capped by the plan.

The token needs `catalog:manage` and `catalog:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "platform" {
  full_path = "acme/platform"
}

data "gitmoap_repository_by_path" "api" {
  full_path = "acme/platform/api"
}

resource "gitmoap_catalog_service" "payments" {
  group_id        = data.gitmoap_group_by_path.platform.group_id
  slug            = "payments"
  display_name    = "Payments"
  kind            = "service"
  description     = "Takes card payments"
  lifecycle_stage = "production"
  annotations     = jsonencode({ "pagerduty/service" = "PX1234" })

  # The service's code: everything under services/payments in the api repository.
  repo_paths = [{
    repository_id = data.gitmoap_repository_by_path.api.repository_id
    path_glob     = "services/payments/**"
  }]

  links = [{
    link_type = "runbook"
    url       = "https://runbooks.example.com/payments"
  }]
}
```

### A service in the catalog, with its environments

The payments service is one folder of the services monorepo: the catalog knows where its code is,
where it deploys, and what each environment gives it. Production only takes deploys from main,
one at a time, approved by a Maintainer other than whoever started them.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

locals {
  group_id = data.gitmoap_group_by_path.acme.group_id
}

# A monorepo, with a folder for each service.
resource "gitmoap_repository" "services" {
  group_id        = local.group_id
  repository_name = "services"
  visibility      = "private"
}

resource "gitmoap_catalog_service" "payments" {
  group_id        = local.group_id
  slug            = "payments"
  display_name    = "Payments"
  kind            = "service"
  description     = "Takes card payments"
  lifecycle_stage = "production"

  repo_paths = [{
    repository_id = gitmoap_repository.services.repository_id
    path_glob     = "payments/**"
  }]

  links = [
    { link_type = "runbook", url = "https://runbooks.example.com/payments" },
    { link_type = "dashboard", url = "https://grafana.example.com/d/payments" },
  ]
}

resource "gitmoap_group_catalog_environment" "staging" {
  group_id     = local.group_id
  slug         = "staging"
  display_name = "Staging"
  tier         = "staging"
}

resource "gitmoap_group_catalog_environment" "production" {
  group_id     = local.group_id
  slug         = "production"
  display_name = "Production"
  tier         = "production"

  # Deploys come from main, one at a time, once a Maintainer other than whoever started them
  # approves.
  protection = {
    allowed_refs          = ["main"]
    requires_approval     = true
    required              = 1
    prevent_self_approval = true
    approvers = [
      { role = { min = "maintainer", at = { group = local.group_id } } },
    ]
  }

  concurrency = {
    exclusive = true
  }
}

# The card processor's URL, set for each environment.
locals {
  environments = {
    staging    = gitmoap_group_catalog_environment.staging.environment_id
    production = gitmoap_group_catalog_environment.production.environment_id
  }
  card_api_urls = {
    staging    = "https://sandbox.cards.example.com"
    production = "https://cards.example.com"
  }
}

resource "gitmoap_catalog_environment_variable" "card_api_url" {
  for_each = local.card_api_urls

  environment_id = local.environments[each.key]
  name           = "CARD_API_URL"
  value          = each.value
}

# How services in production measure up.
resource "gitmoap_catalog_scorecard" "production_ready" {
  group_id = local.group_id
  slug     = "production-ready"
  name     = "Production ready"

  applies_to = {
    kinds      = ["service"]
    lifecycles = ["production"]
  }
}
```

### Optional

- `kind` (String) What sort of thing a service is. The kind decides which scorecard checks apply: a `library` has
no deployments, so a deployment check is not applicable to it rather than failing. For your own
classifications, use annotations.

### Read-Only

- `created_at` (String)
- `created_by` (Attributes) Who did something — a person, a service account or an AI organization's agent — with what a
client needs to draw and link them, so a page of records names its actors without a lookup each. (see [below for nested schema](#nestedatt--created_by))
- `orphaned_at` (String) When the catalog file declaring this service stopped declaring it. The service is kept, with
its history, rather than deleted.
- `owner` (Attributes) Who owns a service: a group, a team, or a person or service account. A service may also have no
owner, which the `has_owner` scorecard check surfaces.

`kind` says which applies: `group`, with `full_path`, `group_id`; `principal`, with `actor`, `principal_id`; `team`, with `organization`, `slug`, `team_id`. (see [below for nested schema](#nestedatt--owner))
- `service_id` (String) The service's id
- `source` (String) How the catalog entry came to exist. Set by the platform, never accepted from a request. Any
source other than `inferred` means a person has vouched for the entry.
- `updated_at` (String)
- `version` (Number) The service's revision, incremented on every change. Send it with an update to have the
update refused with a `409` if someone changed the service since you read it.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# Import by its group_id and service_id, joined with slashes.
terraform import gitmoap_catalog_service.example "<group_id>/<service_id>"
```
