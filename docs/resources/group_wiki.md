# gitmoap_group_wiki (Resource)

The first call creates the wiki; settings you leave out take their defaults — enabled, with `home` as the home page. Later calls change only the fields you send. A group's wiki always keeps its pages in its own repository: a group has no default branch to read them from, so that source is refused. Maintainers and above.

The token needs `wiki:manage` and `wiki:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "platform" {
  full_path = "acme/platform"
}

resource "gitmoap_group_wiki" "platform" {
  group_id     = data.gitmoap_group_by_path.platform.group_id
  enabled      = true
  source       = "dedicated"
  default_page = "home"
}
```

### A wiki written in Markdown files

The wiki's pages live next to the configuration, one Markdown file each, and each page takes its
title from its file's first heading. Adding a file adds a page; deleting one deletes it.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

resource "gitmoap_group_wiki" "acme" {
  group_id     = data.gitmoap_group_by_path.acme.group_id
  enabled      = true
  source       = "dedicated"
  default_page = "home"
}

resource "gitmoap_group_wiki_page" "pages" {
  for_each = fileset("${path.module}/wiki", "*.md")

  group_id = data.gitmoap_group_by_path.acme.group_id
  path     = trimsuffix(each.value, ".md")
  title    = trimprefix(split("\n", file("${path.module}/wiki/${each.value}"))[0], "# ")
  content  = file("${path.module}/wiki/${each.value}")

  depends_on = [gitmoap_group_wiki.acme]
}
```

## Schema

### Required

- `group_id` (String) Group ID

### Optional

- `default_page` (String)
- `enabled` (Boolean) Whether the wiki is on. **A disabled wiki is `false` here, never a `404`**: whether a wiki
exists is not a secret, and only its contents are.
- `source` (String) Where a wiki's pages come from.
- `source_path` (String)

### Read-Only

- `clone_url` (String) Where this wiki can be cloned from. Absent when the wiki has no clone URL of its own, as for
a wiki that reads its pages from a repository.
- `created_at` (String)
- `created_by` (Attributes) Who did something — a person, a service account or an AI organization's agent — with what a
client needs to draw and link them, so a page of records names its actors without a lookup each. (see [below for nested schema](#nestedatt--created_by))
- `head_sha` (String)
- `indexed_at` (String)
- `page_count` (Number) How many pages the wiki has.
- `scope_id` (String)
- `scope_type` (String)
- `updated_at` (String)
- `wiki_id` (String)

### Nested Schema for `created_by`

Read-Only:

- `avatar_url` (String) The principal's picture, when one is known. Absent otherwise: a client derives the
deterministic avatar URL itself.
- `email` (String) The principal's address. An agent's is a generated no-reply address — the author of its
commits. `unknown` on a deleted actor and empty on a redacted one.
- `id` (String) The principal's id: a user id, a service account id or an agent id, as `kind` says. Empty on
a redacted actor.
- `kind` (String) A person, a service account or an AI organization's agent — which of the three a principal is,
and so which page it links to: a person's profile, a service account's page or an agent's page.
- `username` (String) The name to show: a person's or service account's username, or an agent's handle (which
always ends in `-ai`). `deleted-user` when the actor no longer resolves, `redacted` when the
caller may not see who it was. A closed account whose work stays is `closed-` and twelve hex
digits, a shape no open account may take, with an address under `.invalid`.
