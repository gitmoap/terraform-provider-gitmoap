# gitmoap_group_catalog_environment (Resource)

Declares an environment, a place services deploy to, that every repository beneath the group can deploy to unless it declares its own environment with the same slug. Maintainers and above may declare one; a production-tier environment needs an Owner. Unless you set its protection, a production environment requires an approval from the group's direct members before each deploy and accepts deploys from `main` only.

The token needs `catalog:manage` and `catalog:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "platform" {
  full_path = "acme/platform"
}

resource "gitmoap_group_catalog_environment" "production" {
  group_id     = data.gitmoap_group_by_path.platform.group_id
  slug         = "production"
  display_name = "Production"
  tier         = "production"
  url          = "https://api.example.com"

  # Deploys come from main only, once a Maintainer other than whoever started them approves.
  protection = {
    allowed_refs          = ["main"]
    requires_approval     = true
    required              = 1
    prevent_self_approval = true
    approvers = [
      { role = { min = "maintainer", at = { group = data.gitmoap_group_by_path.platform.group_id } } },
    ]
  }

  concurrency = {
    exclusive = true
  }
}
```

### A service in the catalog, with its environments

The payments service is one folder of the services monorepo: the catalog knows where its code is,
where it deploys, and what each environment gives it. Production only takes deploys from main,
one at a time, approved by a Maintainer other than whoever started them.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

locals {
  group_id = data.gitmoap_group_by_path.acme.group_id
}

# A monorepo, with a folder for each service.
resource "gitmoap_repository" "services" {
  group_id        = local.group_id
  repository_name = "services"
  visibility      = "private"
}

resource "gitmoap_catalog_service" "payments" {
  group_id        = local.group_id
  slug            = "payments"
  display_name    = "Payments"
  kind            = "service"
  description     = "Takes card payments"
  lifecycle_stage = "production"

  repo_paths = [{
    repository_id = gitmoap_repository.services.repository_id
    path_glob     = "payments/**"
  }]

  links = [
    { link_type = "runbook", url = "https://runbooks.example.com/payments" },
    { link_type = "dashboard", url = "https://grafana.example.com/d/payments" },
  ]
}

resource "gitmoap_group_catalog_environment" "staging" {
  group_id     = local.group_id
  slug         = "staging"
  display_name = "Staging"
  tier         = "staging"
}

resource "gitmoap_group_catalog_environment" "production" {
  group_id     = local.group_id
  slug         = "production"
  display_name = "Production"
  tier         = "production"

  # Deploys come from main, one at a time, once a Maintainer other than whoever started them
  # approves.
  protection = {
    allowed_refs          = ["main"]
    requires_approval     = true
    required              = 1
    prevent_self_approval = true
    approvers = [
      { role = { min = "maintainer", at = { group = local.group_id } } },
    ]
  }

  concurrency = {
    exclusive = true
  }
}

# The card processor's URL, set for each environment.
locals {
  environments = {
    staging    = gitmoap_group_catalog_environment.staging.environment_id
    production = gitmoap_group_catalog_environment.production.environment_id
  }
  card_api_urls = {
    staging    = "https://sandbox.cards.example.com"
    production = "https://cards.example.com"
  }
}

resource "gitmoap_catalog_environment_variable" "card_api_url" {
  for_each = local.card_api_urls

  environment_id = local.environments[each.key]
  name           = "CARD_API_URL"
  value          = each.value
}

# How services in production measure up.
resource "gitmoap_catalog_scorecard" "production_ready" {
  group_id = local.group_id
  slug     = "production-ready"
  name     = "Production ready"

  applies_to = {
    kinds      = ["service"]
    lifecycles = ["production"]
  }
}
```

### Optional

- `archived` (Boolean) Whether the environment is archived. An archived environment can no longer be deployed to
but keeps its deployment history, and archiving can be undone. An environment with
deployments cannot be deleted, only archived.
- `concurrency` (Attributes) Whether deploys to an environment run one at a time, and what happens to a deploy that has to

- `protection` (Attributes) The rules for deploying to an environment: whether a deployment needs approval and from whom,
which refs may deploy, and which groups and repositories may use it. Approvers are checked when
the approval is given, so a change in who belongs to a team applies at once. (see [below for nested schema](#nestedatt--protection))
- `tier` (String) What kind of environment this is, whatever it is called: `development`, `testing`, `staging`
or `production`. A `production` environment is protected by default.
- `url` (String)

### Read-Only

a policy that is applied from one that is only recorded.
- `created_at` (String)
- `created_by` (Attributes) Who did something — a person, a service account or an AI organization's agent — with what a

- `environment_id` (String) The environment's id
- `owner_full_path` (String) The full path of the group or repository that owns the environment (e.g. `acme/platform`),

the slug it forms the environment's OIDC claim, `{owner_full_path}:{slug}`.
- `scope` (Attributes) A group or a repository, whichever a setting belongs to.

- `updated_at` (String)
- `variable_count` (Number) How many variables the environment holds.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# Import by its group_id and environment_id, joined with slashes.
terraform import gitmoap_group_catalog_environment.example "<group_id>/<environment_id>"
```
