# gitmoap_group_iteration_cadence (Resource)

Creates a schedule that generates the group's iterations: each runs `duration_weeks` weeks, starting on `start_day`, from the first such day on or after `first_start_date`, with `cool_down_weeks` weeks between one iteration and the next — set it for Shape Up's cool-down. The current iteration and the next `iterations_in_advance` are created straight away and kept topped up every day, each counting toward the group's iteration limit; a cadence at that limit stops generating until one is deleted. The schedule cannot be changed afterwards. Maintainers and above may create cadences, up to the group's cadence limit.

The token needs `iteration:manage` and `issue:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "platform" {
  full_path = "acme/platform"
}

# Two-week sprints starting on Mondays, keeping the next two created.
resource "gitmoap_group_iteration_cadence" "sprints" {
  group_id              = data.gitmoap_group_by_path.platform.group_id
  title                 = "Sprint"
  first_start_date      = "2027-01-04"
  start_day             = "monday"
  duration_weeks        = 2
  iterations_in_advance = 2
}
```

### Sprints, a milestone, and a hardening week

A cadence keeps two-week sprints created ahead of time. A milestone marks what has to land for a
launch, and an iteration outside the cadence covers the week before it.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

resource "gitmoap_group_iteration_cadence" "sprints" {
  group_id              = data.gitmoap_group_by_path.acme.group_id
  title                 = "Sprint"
  first_start_date      = "2027-01-04"
  start_day             = "monday"
  duration_weeks        = 2
  iterations_in_advance = 3
}

resource "gitmoap_group_milestone" "launch" {
  group_id    = data.gitmoap_group_by_path.acme.group_id
  title       = "Public launch"
  description = "Everything that has to land before launch"
  due_on      = "2027-03-31"
}

# Already behind us. Only an update can close a milestone: the provider creates it, then closes it.
resource "gitmoap_group_milestone" "beta" {
  group_id = data.gitmoap_group_by_path.acme.group_id
  title    = "Private beta"
  due_on   = "2026-12-15"
  closed   = true
}

resource "gitmoap_group_iteration" "hardening" {
  group_id    = data.gitmoap_group_by_path.acme.group_id
  title       = "Hardening before launch"
  description = "No new features: fix, test and tidy up."
  start_date  = "2027-03-22"
  due_date    = "2027-03-26"
}
```

## Schema

### Required

- `first_start_date` (String) A calendar day, `YYYY-MM-DD`, with no time and no zone — a due date, or the day an iteration starts or ends.
- `group_id` (String) Group ID
- `title` (String) A cadence's title, such as Sprint: 1 to 120 characters, with no control characters. Each iteration it generates is titled with it and the iteration's number.

### Optional

- `active` (Boolean) Whether it starts generating straight away. Defaults to true.
- `cool_down_weeks` (Number) Weeks left between iterations that belong to none: 0 to 4. Defaults to 0.
- `duration_weeks` (Number) How long each iteration runs, in weeks: 1 to 12. Defaults to 2.
- `iterations_in_advance` (Number) How many upcoming iterations to keep created ahead of today: 1 to 12. Defaults to 4.
- `start_day` (String) A day of the week.

### Read-Only

- `at_limit` (Boolean) Whether its group holds as many iterations as its plan allows, so nothing it owes can be
created until an iteration is deleted or the limit is raised.
- `cadence_id` (String) The identifier of an iteration cadence — the schedule that generates a group's iterations.
- `created_at` (String) When it was created, ISO 8601.
- `followed_by_ai_organization` (Boolean) Whether the group's AI organization runs its cycles on it — its live revision names it in
`calendar.cycle_cadence`. Such a cadence can be neither paused nor deleted.
- `generated_through` (Number) The number of the last iteration it has generated, or 0 before the first.
- `owed` (Number) How many iterations it owes today and has not created: its group is at its iteration limit,
or the daily generator has yet to run. 0 when it is up to date, and while it is paused.
- `updated_at` (String) When it last changed, ISO 8601.
