# gitmoap_group_sso_connection (Resource)

Only the organization's owners configure it, on its top-level group. The body names one protocol — SAML 2.0 (a metadata URL or document) or OpenID Connect (issuer, client id and secret) — with the attribute mapping, whether newcomers on verified domains get an account at their first sign-in, whether sign-in through the provider is enforced, and the role newcomers receive (Reporter by default). The provider is set up straight away and the response says whether that worked (`active`) or not (`failed`, with the error); a change made while another is still being set up is refused.

The token needs `sso:manage` and `sso:read`.

## Example Usage

### Basic Usage

```terraform
variable "oidc_client_secret" {
  type      = string
  sensitive = true
  ephemeral = true
}

data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

resource "gitmoap_group_sso_connection" "acme" {
  group_id = data.gitmoap_group_by_path.acme.group_id
  protocol = "oidc"

  oidc = {
    issuer_url               = "https://acme.okta.com"
    client_id                = "0oa1b2c3d4e5f6g7h8i9"
    client_secret_wo         = var.oidc_client_secret
    client_secret_wo_version = 1
  }

  # Create an account the first time someone from a verified domain signs in.
  auto_provision = true
}
```

### Single sign-on through an identity provider

The organization signs people in through Okta over OIDC: it claims its domain, connects the
identity provider, and gives it a SCIM token to create and remove accounts. Someone from outside
the domain gets an invite. Once `enforced`, everyone from the domain has to sign in through Okta,
so check the connection works first.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

variable "oidc_client_secret" {
  description = "The client secret of the gitmoap app in Okta."
  type        = string
  sensitive   = true
  ephemeral   = true
}

locals {
  group_id = data.gitmoap_group_by_path.acme.group_id
}

# Proven with the DNS record the domain's attributes describe.
resource "gitmoap_group_sso_domain" "acme" {
  group_id = local.group_id
  domain   = "acme.com"
}

resource "gitmoap_group_sso_connection" "okta" {
  group_id = local.group_id
  protocol = "oidc"

  oidc = {
    issuer_url               = "https://acme.okta.com"
    client_id                = "0oa1b2c3d4e5f6g7h8i9"
    client_secret_wo         = var.oidc_client_secret
    client_secret_wo_version = 1
  }

  attribute_mapping = {
    email    = "email"
    username = "preferred_username"
    groups   = "groups"
  }

  auto_provision = true
  enforced       = true

  depends_on = [gitmoap_group_sso_domain.acme]
}

# Okta creates and removes accounts through SCIM with this token.
resource "gitmoap_group_scim_token" "okta" {
  group_id = local.group_id
  name     = "Okta"
}

output "scim_token" {
  value     = gitmoap_group_scim_token.okta.secret
  sensitive = true
}

# A contractor from outside acme.com, until the contract ends.
resource "gitmoap_group_sso_invite" "contractor" {
  group_id   = local.group_id
  email      = "ada@contractor.example.com"
  reason     = "Payments migration"
  expires_at = "2027-03-31T00:00:00Z"
}
```
