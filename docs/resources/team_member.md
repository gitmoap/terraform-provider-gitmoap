# gitmoap_team_member (Resource)

Sets the person's role on the team (member or maintainer) and an optional end date. The team's maintainers, and whoever manages the organization's teams, may call it; when the change gives more — a new place, a higher role, a later end — the caller must also be able to give every grant the team holds. Only people join teams, and a roster kept by the identity provider is changed there instead. Answers `201` when the person is added and `200` when their place changes; with `dry_run=true` it says what they would gain, and nothing changes.

The token needs `team:manage` and `team:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

resource "gitmoap_team" "reviewers" {
  group_id = data.gitmoap_group_by_path.acme.group_id
  name     = "Reviewers"
  slug     = "reviewers"
}

data "gitmoap_user_by_username" "ada" {
  username = "ada"
}

resource "gitmoap_team_member" "ada" {
  team_id = gitmoap_team.reviewers.team_id
  user_id = data.gitmoap_user_by_username.ada.user_id
  role    = "maintainer"
}
```

### A team, with its members found by username

Teams belong to an organization's top-level group. Their members are separate resources, so
adding or removing one person changes only that membership. Whoever creates a team becomes one
of its maintainers.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

variable "reviewers" {
  description = "Usernames of the people who review changes."
  type        = set(string)
  default     = ["ada", "grace"]
}

data "gitmoap_user_by_username" "reviewers" {
  for_each = var.reviewers

  username = each.value
}

resource "gitmoap_team" "reviewers" {
  group_id    = data.gitmoap_group_by_path.acme.group_id
  name        = "Reviewers"
  slug        = "reviewers"
  description = "Reviews changes before they merge"
}

resource "gitmoap_team_member" "reviewers" {
  for_each = var.reviewers

  team_id = gitmoap_team.reviewers.team_id
  user_id = data.gitmoap_user_by_username.reviewers[each.key].user_id
  role    = "maintainer"
}
```
