# gitmoap_group_scim_token (Resource)

Only the organization's owners mint tokens, on its top-level group. The response carries the token's secret this once: paste it into the identity provider, which sends it as a bearer token to the SCIM 2.0 endpoints. While the organization holds a live token, its identity provider keeps team rosters through SCIM, and signing in no longer syncs them from the groups claim.

The token needs `sso:manage` and `sso:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

# A token for the identity provider to provision people with SCIM.
resource "gitmoap_group_scim_token" "okta" {
  group_id = data.gitmoap_group_by_path.acme.group_id
  name     = "Okta"
}

# The secret is only returned when the token is created: give it to the identity provider.
output "scim_token" {
  value     = gitmoap_group_scim_token.okta.secret
  sensitive = true
}
```

### Single sign-on through an identity provider

The organization signs people in through Okta over OIDC: it claims its domain, connects the
identity provider, and gives it a SCIM token to create and remove accounts. Someone from outside
the domain gets an invite. Once `enforced`, everyone from the domain has to sign in through Okta,
so check the connection works first.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

variable "oidc_client_secret" {
  description = "The client secret of the gitmoap app in Okta."
  type        = string
  sensitive   = true
  ephemeral   = true
}

locals {
  group_id = data.gitmoap_group_by_path.acme.group_id
}

# Proven with the DNS record the domain's attributes describe.
resource "gitmoap_group_sso_domain" "acme" {
  group_id = local.group_id
  domain   = "acme.com"
}

resource "gitmoap_group_sso_connection" "okta" {
  group_id = local.group_id
  protocol = "oidc"

  oidc = {
    issuer_url               = "https://acme.okta.com"
    client_id                = "0oa1b2c3d4e5f6g7h8i9"
    client_secret_wo         = var.oidc_client_secret
    client_secret_wo_version = 1
  }

  attribute_mapping = {
    email    = "email"
    username = "preferred_username"
    groups   = "groups"
  }

  auto_provision = true
  enforced       = true

  depends_on = [gitmoap_group_sso_domain.acme]
}

# Okta creates and removes accounts through SCIM with this token.
resource "gitmoap_group_scim_token" "okta" {
  group_id = local.group_id
  name     = "Okta"
}

output "scim_token" {
  value     = gitmoap_group_scim_token.okta.secret
  sensitive = true
}

# A contractor from outside acme.com, until the contract ends.
resource "gitmoap_group_sso_invite" "contractor" {
  group_id   = local.group_id
  email      = "ada@contractor.example.com"
  reason     = "Payments migration"
  expires_at = "2027-03-31T00:00:00Z"
}
```

## Schema

### Required

- `group_id` (String) The organization's top-level group
- `name` (String) What it is for, such as the identity provider it is given to. 1–100 characters.

### Read-Only

- `created_at` (String)
- `created_by` (Attributes) Who did something — a person, a service account or an AI organization's agent — with what a
client needs to draw and link them, so a page of records names its actors without a lookup each. (see [below for nested schema](#nestedatt--created_by))
- `last_used_at` (String)
- `organization_id` (String)
- `revoked_at` (String) When it was revoked. A revoked token is kept for the audit trail and authenticates nothing.
- `scim_token_id` (String)
- `secret` (String, Sensitive) The bearer the identity provider sends. Shown once, and never again.

### Nested Schema for `created_by`

Read-Only:

- `avatar_url` (String) The principal's picture, when one is known. Absent otherwise: a client derives the
deterministic avatar URL itself.
- `email` (String) The principal's address. An agent's is a generated no-reply address — the author of its
commits. `unknown` on a deleted actor and empty on a redacted one.
- `id` (String) The principal's id: a user id, a service account id or an agent id, as `kind` says. Empty on
a redacted actor.
- `kind` (String) A person, a service account or an AI organization's agent — which of the three a principal is,
and so which page it links to: a person's profile, a service account's page or an agent's page.
- `username` (String) The name to show: a person's or service account's username, or an agent's handle (which
always ends in `-ai`). `deleted-user` when the actor no longer resolves, `redacted` when the
caller may not see who it was. A closed account whose work stays is `closed-` and twelve hex
digits, a shape no open account may take, with an address under `.invalid`.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# Import by its group_id and scim_token_id, joined with slashes.
terraform import gitmoap_group_scim_token.example "<group_id>/<scim_token_id>"
```
