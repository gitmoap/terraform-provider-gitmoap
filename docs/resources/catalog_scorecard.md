# gitmoap_catalog_scorecard (Resource)

A scorecard is a set of checks, and optionally named levels built from them, that every matching service in this group and the groups beneath it is measured against. Maintainers and above may declare one, but only the group's Owners may create it with its campaign armed, since an armed campaign files work items in every owning team's backlog. The slug must be unique here, each level may only require checks the scorecard carries, and the number of scorecards is capped by the plan.

The token needs `catalog:manage` and `catalog:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "platform" {
  full_path = "acme/platform"
}

resource "gitmoap_catalog_scorecard" "production_ready" {
  group_id    = data.gitmoap_group_by_path.platform.group_id
  slug        = "production-ready"
  name        = "Production ready"
  description = "What a service needs before it takes production traffic"

  applies_to = {
    kinds      = ["service", "api"]
    lifecycles = ["production"]
  }
}
```

### A service in the catalog, with its environments

The payments service is one folder of the services monorepo: the catalog knows where its code is,
where it deploys, and what each environment gives it. Production only takes deploys from main,
one at a time.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

locals {
  group_id = data.gitmoap_group_by_path.acme.group_id
}

# A monorepo, with a folder for each service.
resource "gitmoap_repository" "services" {
  group_id        = local.group_id
  repository_name = "services"
  visibility      = "private"
}

resource "gitmoap_catalog_service" "payments" {
  group_id     = local.group_id
  slug         = "payments"
  display_name = "Payments"
  kind         = "service"
  description  = "Takes card payments"

  repo_paths = [{
    repository_id = gitmoap_repository.services.repository_id
    path_glob     = "payments/**"
  }]

  links = [
    { link_type = "runbook", url = "https://runbooks.example.com/payments" },
    { link_type = "dashboard", url = "https://grafana.example.com/d/payments" },
  ]
}

resource "gitmoap_group_catalog_environment" "staging" {
  group_id     = local.group_id
  slug         = "staging"
  display_name = "Staging"
  tier         = "staging"
}

resource "gitmoap_group_catalog_environment" "production" {
  group_id     = local.group_id
  slug         = "production"
  display_name = "Production"
  tier         = "production"

  # Deploys come from main, one at a time.
  protection = {
    allowed_refs = ["main"]
  }

  concurrency = {
    exclusive = true
  }
}

# The card processor's URL, set for each environment.
locals {
  environments = {
    staging    = gitmoap_group_catalog_environment.staging.environment_id
    production = gitmoap_group_catalog_environment.production.environment_id
  }
  card_api_urls = {
    staging    = "https://sandbox.cards.example.com"
    production = "https://cards.example.com"
  }
}

resource "gitmoap_catalog_environment_variable" "card_api_url" {
  for_each = local.card_api_urls

  environment_id = local.environments[each.key]
  name           = "CARD_API_URL"
  value          = each.value
}

# How services in production measure up.
resource "gitmoap_catalog_scorecard" "production_ready" {
  group_id = local.group_id
  slug     = "production-ready"
  name     = "Production ready"

  applies_to = {
    kinds      = ["service"]
    lifecycles = ["production"]
  }
}
```

## Schema

### Required

- `group_id` (String) The owning group's id
- `slug` (String)

### Optional

- `applies_to` (Attributes) Which services a scorecard covers. A service must match every field that is set; with every field
empty, the scorecard covers every service beneath the group or repository that owns it. (see [below for nested schema](#nestedatt--applies_to))
- `campaign_active` (Boolean) Whether to switch the campaign on from the start. Setting it to `true` requires the Owner
role.
- `campaign_max_items` (Number) How many work items the campaign may file each time it is switched on. Defaults to 200; at
most 1,000.
- `checks` (Attributes List) (see [below for nested schema](#nestedatt--checks))
- `description` (String)
- `enabled` (Boolean)
- `levels` (Attributes List) (see [below for nested schema](#nestedatt--levels))
- `name` (String) Defaults to the slug.

### Read-Only

- `campaign_enforced` (Boolean) Whether the platform acts on `campaign_active`. Always `true`.
- `campaign_item_count` (Number) How many work items the campaign has filed since it was last switched on. Read-only.
- `created_at` (String)
- `created_by` (Attributes) Who did something — a person, a service account or an AI organization's agent — with what a
client needs to draw and link them, so a page of records names its actors without a lookup each. (see [below for nested schema](#nestedatt--created_by))
- `scorecard_id` (String) The scorecard's id
- `updated_at` (String)
- `version` (Number) The scorecard's revision, incremented on every change. Send it with an update to have the
update refused with a `409` if someone changed the scorecard since you read it.

### Nested Schema for `created_by`

Read-Only:

- `avatar_url` (String) The principal's picture, when one is known. Absent otherwise: a client derives the
deterministic avatar URL itself.
- `email` (String) The principal's address. An agent's is a generated no-reply address — the author of its
commits. `unknown` on a deleted actor and empty on a redacted one.
- `id` (String) The principal's id: a user id, a service account id or an agent id, as `kind` says. Empty on
a redacted actor.
- `kind` (String) A person, a service account or an AI organization's agent — which of the three a principal is,
and so which page it links to: a person's profile, a service account's page or an agent's page.
- `username` (String) The name to show: a person's or service account's username, or an agent's handle (which
always ends in `-ai`). `deleted-user` when the actor no longer resolves, `redacted` when the
caller may not see who it was. A closed account whose work stays is `closed-` and twelve hex
digits, a shape no open account may take, with an address under `.invalid`.

## Import

Import is supported using the following syntax:

```shell
# Import by its group_id and scorecard_id, joined with slashes.
terraform import gitmoap_catalog_scorecard.example "<group_id>/<scorecard_id>"
```
