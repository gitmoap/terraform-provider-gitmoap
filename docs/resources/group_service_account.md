# gitmoap_group_service_account (Resource)

A group's service account reaches every repository beneath the group at the access level it is given — Maintainer at most, never Owner, and never above the caller's own. It gets a generated username and email. Only the group's owners may create one, as people rather than service accounts.

The token needs `service_account:create`, `service_account:read`, `service_account:update` and `service_account:delete`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "platform" {
  full_path = "acme/platform"
}

resource "gitmoap_group_service_account" "ci" {
  group_id     = data.gitmoap_group_by_path.platform.group_id
  name         = "ci"
  access_level = "developer"
}
```

### A service account for CI, its token stored for the pipelines

A service account gets the access it needs and no more. Its token is narrowed further, to read
one repository, and handed to that repository's pipelines as a secret variable: nobody copies it
by hand. To rotate it, run `terraform apply -replace=gitmoap_service_account_token.ci`.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

resource "gitmoap_repository" "api" {
  group_id        = data.gitmoap_group_by_path.acme.group_id
  repository_name = "api"
  visibility      = "private"
}

resource "gitmoap_group_service_account" "ci" {
  group_id     = data.gitmoap_group_by_path.acme.group_id
  name         = "ci"
  access_level = "reporter"
}

# The token reads the api repository, nothing else, for 90 days.
resource "gitmoap_service_account_token" "ci" {
  sa_id           = gitmoap_group_service_account.ci.service_account_id
  name            = "ci-api"
  scopes          = ["repo:read"]
  expires_in_days = 90

  resource = {
    scope_type = "repository"
    scope_id   = gitmoap_repository.api.repository_id
  }
}

# Only runs on protected branches and tags receive it, and the value is never shown.
resource "gitmoap_repository_pipeline_variable" "ci_token" {
  repo_id   = gitmoap_repository.api.repository_id
  name      = "CI_TOKEN"
  value     = gitmoap_service_account_token.ci.token
  secret    = true
  protected = true
}
```

### Nested Schema for `created_by`

Read-Only:

- `avatar_url` (String) The principal's picture, when one is known. Absent otherwise: a client derives the
deterministic avatar URL itself.
- `email` (String) The principal's address. An agent's is a generated no-reply address — the author of its
commits. `unknown` on a deleted actor and empty on a redacted one.
- `id` (String) The principal's id: a user id, a service account id or an agent id, as `kind` says. Empty on
a redacted actor.
- `kind` (String) A person, a service account or an AI organization's agent — which of the three a principal is,
and so which page it links to: a person's profile, a service account's page or an agent's page.
- `username` (String) The name to show: a person's or service account's username, or an agent's handle (which
always ends in `-ai`). `deleted-user` when the actor no longer resolves, `redacted` when the
caller may not see who it was. A closed account whose work stays is `closed-` and twelve hex
digits, a shape no open account may take, with an address under `.invalid`.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# Import by its group_id and service_account_id, joined with slashes.
terraform import gitmoap_group_service_account.example "<group_id>/<service_account_id>"
```
