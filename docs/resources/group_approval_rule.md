# gitmoap_group_approval_rule (Resource)

A rule requires 1 to 10 approvals before a merge request into the matching branches can merge, from approvers you name — people, teams, a role at a group or repository, code owners, or anyone who may approve — and says which kinds of approval count. Maintainers and above may define one; an enforced rule, which applies beneath and may only be strengthened there, needs an Owner. Name an enforced rule from above in `strengthens` to replace it here with a rule at least as strong.

The token needs `approval_rule:manage` and `approval_rule:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

data "gitmoap_group_by_path" "platform" {
  full_path = "acme/platform"
}

resource "gitmoap_team" "reviewers" {
  group_id = data.gitmoap_group_by_path.acme.group_id
  name     = "Reviewers"
  slug     = "reviewers"
}

# Two approvals before anything merges into main: from the reviewers team, or from anyone who's at
# least a Maintainer of the group.
resource "gitmoap_group_approval_rule" "reviewed" {
  group_id            = data.gitmoap_group_by_path.platform.group_id
  name                = "Reviewed"
  required            = 2
  applies_to_branches = "main"

  approvers = [
    { team = gitmoap_team.reviewers.team_id },
    { role = { min = "maintainer", at = { group = data.gitmoap_group_by_path.platform.group_id } } },
  ]
}
```

### Reviews, by a team given access

A team of reviewers is given access to the payments group through a grant, and an approval rule
asks for one of their approvals before anything merges into main in any of the group's
repositories.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

resource "gitmoap_group" "payments" {
  group_name      = "payments"
  parent_group_id = data.gitmoap_group_by_path.acme.group_id
  visibility      = "private"
}

# Teams belong to the organization's top-level group.
resource "gitmoap_team" "reviewers" {
  group_id    = data.gitmoap_group_by_path.acme.group_id
  name        = "Payments reviewers"
  slug        = "payments-reviewers"
  description = "Reviews changes to payments"
}

resource "gitmoap_group_access_grant" "reviewers" {
  group_id = gitmoap_group.payments.group_id
  subject  = { team = gitmoap_team.reviewers.team_id }
  role     = { builtin = "developer" }
  reason   = "Reviews changes to payments"
}

resource "gitmoap_group_approval_rule" "reviewed" {
  group_id            = gitmoap_group.payments.group_id
  name                = "Reviewed by payments"
  required            = 1
  applies_to_branches = "main"
  approvers           = [{ team = gitmoap_team.reviewers.team_id }]
}
```
