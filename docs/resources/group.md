# gitmoap_group (Resource)

Creates a group, a namespace for repositories and other groups. Without a parent it is a top-level group — an organization — which any signed-in person can create, up to a limit; under a parent it needs Maintainer on the parent and can be no more visible than the parent. You become the new group's Owner in the same act, and its path must not be taken by another group or a repository. An organization's name must not be one the platform keeps, a well-known organization's name or one that looks like it, or a name another organization gave up recently; a well-known organization takes its own name by verifying its domain, then renaming.

The token needs `group:create`, `group:read`, `group:update` and `group:delete`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

resource "gitmoap_group" "platform" {
  group_name      = "platform"
  parent_group_id = data.gitmoap_group_by_path.acme.group_id
  description     = "Shared services and the tools around them"
  visibility      = "internal"
}
```

### Reviews, by a team given access

A team of reviewers is given access to the payments group through a grant, and an approval rule
asks for one of their approvals before anything merges into main in any of the group's
repositories.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

resource "gitmoap_group" "payments" {
  group_name      = "payments"
  parent_group_id = data.gitmoap_group_by_path.acme.group_id
  visibility      = "private"
}

# Teams belong to the organization's top-level group.
resource "gitmoap_team" "reviewers" {
  group_id    = data.gitmoap_group_by_path.acme.group_id
  name        = "Payments reviewers"
  slug        = "payments-reviewers"
  description = "Reviews changes to payments"
}

resource "gitmoap_group_access_grant" "reviewers" {
  group_id = gitmoap_group.payments.group_id
  subject  = { team = gitmoap_team.reviewers.team_id }
  role     = { builtin = "developer" }
  reason   = "Reviews changes to payments"
}

resource "gitmoap_group_approval_rule" "reviewed" {
  group_id            = gitmoap_group.payments.group_id
  name                = "Reviewed by payments"
  required            = 1
  applies_to_branches = "main"
  approvers           = [{ team = gitmoap_team.reviewers.team_id }]
}
```
