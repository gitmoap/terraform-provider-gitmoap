# gitmoap_group_access_grant (Resource)

Names up to 50 subjects, with an optional expiry (in the future, at most a year away) and reason. Callers who can manage access here may call it (Maintainers and above with the built-in roles), and nobody can give a role carrying a permission or rank they do not hold themselves. A subject that already holds the same role is reported as unchanged; one holding a different role is refused. A service account can be given access only at its own group or repository or beneath it, and never as Owner. With `dry_run=true` the answer says who would gain what, and nothing changes.

The token needs `access:manage` and `access:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

data "gitmoap_group_by_path" "platform" {
  full_path = "acme/platform"
}

resource "gitmoap_team" "reviewers" {
  group_id = data.gitmoap_group_by_path.acme.group_id
  name     = "Reviewers"
  slug     = "reviewers"
}

# The reviewers team works on everything in the platform group as Developers.
resource "gitmoap_group_access_grant" "reviewers" {
  group_id = data.gitmoap_group_by_path.platform.group_id
  subject  = { team = gitmoap_team.reviewers.team_id }
  role     = { builtin = "developer" }
  reason   = "Reviews the platform's changes"
}
```

### Reviews, by a team given access

A team of reviewers is given access to the payments group through a grant, and an approval rule
asks for one of their approvals before anything merges into main in any of the group's
repositories.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

resource "gitmoap_group" "payments" {
  group_name      = "payments"
  parent_group_id = data.gitmoap_group_by_path.acme.group_id
  visibility      = "private"
}

# Teams belong to the organization's top-level group.
resource "gitmoap_team" "reviewers" {
  group_id    = data.gitmoap_group_by_path.acme.group_id
  name        = "Payments reviewers"
  slug        = "payments-reviewers"
  description = "Reviews changes to payments"
}

resource "gitmoap_group_access_grant" "reviewers" {
  group_id = gitmoap_group.payments.group_id
  subject  = { team = gitmoap_team.reviewers.team_id }
  role     = { builtin = "developer" }
  reason   = "Reviews changes to payments"
}

resource "gitmoap_group_approval_rule" "reviewed" {
  group_id            = gitmoap_group.payments.group_id
  name                = "Reviewed by payments"
  required            = 1
  applies_to_branches = "main"
  approvers           = [{ team = gitmoap_team.reviewers.team_id }]
}
```
