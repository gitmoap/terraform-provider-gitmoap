# gitmoap_repository_tag_rule (Resource)

Protects the repository's tags matching a name or a pattern, where `*` matches anything, `/` included: creating, moving or deleting a matching tag needs at least `allowed_to_create` (Maintainer when left out, Developer at the lowest), over `git push` and the API alike, and a run on a matching tag is a run on a protected ref. Maintainers and above may create one; a pattern takes one rule per repository, and a rule weaker than one a group above enforces for the same pattern is refused.

The token needs `tag_rule:manage` and `tag_rule:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_repository_by_path" "api" {
  full_path = "acme/platform/api"
}

resource "gitmoap_repository_tag_rule" "releases" {
  repo_id           = data.gitmoap_repository_by_path.api.repository_id
  tag_pattern       = "v*"
  allowed_to_create = "maintainer"
}
```

### A release from its own branch

A release is cut from a branch of its own, tagged by a Maintainer, and published with notes kept
next to the configuration. The repository needs at least one commit on main.

```terraform
data "gitmoap_repository_by_path" "api" {
  full_path = "acme/api"
}

locals {
  repo_id = data.gitmoap_repository_by_path.api.repository_id
}

resource "gitmoap_repository_branch" "release" {
  repo_id     = local.repo_id
  branch_name = "release/1.0"
  from_branch = "main"
}

resource "gitmoap_repository_tag_rule" "releases" {
  repo_id           = local.repo_id
  tag_pattern       = "v*"
  allowed_to_create = "maintainer"
}

resource "gitmoap_repository_tag" "v1_0_0" {
  repo_id  = local.repo_id
  tag_name = "v1.0.0"
  target   = gitmoap_repository_branch.release.branch_name
  message  = "Version 1.0.0"

  depends_on = [gitmoap_repository_tag_rule.releases]
}

resource "gitmoap_repository_release" "v1_0_0" {
  repo_id  = local.repo_id
  tag_name = gitmoap_repository_tag.v1_0_0.tag_name
  name     = "1.0.0"
  body     = file("${path.module}/notes/1.0.0.md")
}
```

### A repository stricter than its group

A repository can tighten what it inherits. Branch rules, tag rules, push rules and the approval
policy add to the group's; merge request settings only take over from the group's with
`override_group_settings = true`.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

resource "gitmoap_repository" "payments" {
  group_id          = data.gitmoap_group_by_path.acme.group_id
  repository_name   = "payments"
  description       = "Card payments"
  visibility        = "private"
  pipelines_enabled = true
}

locals {
  repo_id = gitmoap_repository.payments.repository_id
}

# main changes only through merge requests the code owners approve.
resource "gitmoap_repository_branch_rule" "main" {
  repo_id                     = local.repo_id
  branch_pattern              = "main"
  allowed_to_push             = "maintainer"
  allowed_to_merge            = "developer"
  allow_force_push            = false
  require_code_owner_approval = true
}

resource "gitmoap_repository_tag_rule" "releases" {
  repo_id           = local.repo_id
  tag_pattern       = "v*"
  allowed_to_create = "maintainer"
}

# Neither the author nor anyone who pushed to the branch can approve it.
resource "gitmoap_repository_approval_policy" "payments" {
  repo_id                 = local.repo_id
  author_can_approve      = false
  committers_can_approve  = false
  last_pusher_can_approve = false
  reset_on_push           = true
}

# The owners of the files a merge request changes have to approve it.
resource "gitmoap_repository_approval_rule" "code_owners" {
  repo_id   = local.repo_id
  name      = "Code owners"
  required  = 1
  approvers = [{ code_owners = true }]
}

# Every merge is squashed, and only once its pipeline passed.
resource "gitmoap_repository_mr_settings" "payments" {
  repo_id                  = local.repo_id
  override_group_settings  = true
  squash_option            = "require"
  require_pipeline_success = true
}

# Every commit names the work item it's for.
resource "gitmoap_repository_push_rules" "payments" {
  repo_id                 = local.repo_id
  max_file_size_mb        = 5
  require_issue_reference = true
}
```

- `tag_pattern` (String) The tags a tag rule protects: one tag name, or a glob over tag names such as `v*` or `release-*`.

- `enforcement` (String) Whether the scopes beneath may replace a rule, or only strengthen it.
