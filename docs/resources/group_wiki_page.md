# gitmoap_group_wiki_page (Resource)

Writes the page to the wiki as a new commit. The path is the page's address and the title is separate and can change later; the format defaults to Markdown. Refused when a page already exists at the path, when the path starts with `templates/` or `attachments/`, or when the content is larger than 1 MiB. A wiki holds at most 5,000 pages. A wiki that reads its pages from the repository is changed by committing there, not through this API. Developers and above.

The token needs `wiki:write` and `wiki:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "platform" {
  full_path = "acme/platform"
}

resource "gitmoap_group_wiki" "platform" {
  group_id = data.gitmoap_group_by_path.platform.group_id
  enabled  = true
  source   = "dedicated"
}

resource "gitmoap_group_wiki_page" "home" {
  group_id = data.gitmoap_group_by_path.platform.group_id
  path     = "home"
  title    = "Platform"
  content  = <<-EOT
    # Platform
    Start here: how we build, ship and run the platform.
  EOT

  depends_on = [gitmoap_group_wiki.platform]
}
```

### A wiki written in Markdown files

The wiki's pages live next to the configuration, one Markdown file each, and each page takes its
title from its file's first heading. Adding a file adds a page; deleting one deletes it.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

resource "gitmoap_group_wiki" "acme" {
  group_id     = data.gitmoap_group_by_path.acme.group_id
  enabled      = true
  source       = "dedicated"
  default_page = "home"
}

resource "gitmoap_group_wiki_page" "pages" {
  for_each = fileset("${path.module}/wiki", "*.md")

  group_id = data.gitmoap_group_by_path.acme.group_id
  path     = trimsuffix(each.value, ".md")
  title    = trimprefix(split("\n", file("${path.module}/wiki/${each.value}"))[0], "# ")
  content  = file("${path.module}/wiki/${each.value}")

  depends_on = [gitmoap_group_wiki.acme]
}
```
