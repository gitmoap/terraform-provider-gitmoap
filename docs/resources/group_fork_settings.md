# gitmoap_group_fork_settings (Resource)

Sets the group's own fork settings for every repository beneath it; send only the fields you change, and `null` to inherit. A group can also enforce a field with its `_enforced` flag: groups and repositories beneath may then choose a stricter value and never a looser one. Maintainers may change the settings; letting repositories be forked outside the organization, or lifting an enforced flag, needs an Owner. A value looser than one a group above enforces is refused, naming that group.

The token needs `group:update` and `group:read`.

## Example Usage

### Basic Usage

```terraform
data "gitmoap_group_by_path" "platform" {
  full_path = "acme/platform"
}

# Forks stay inside the organization, in every repository beneath the group.
resource "gitmoap_group_fork_settings" "platform" {
  group_id            = data.gitmoap_group_by_path.platform.group_id
  forking             = "organization"
  forking_enforced    = true
  fork_merge_requests = "members"
}
```

### Defaults for every repository in an organization

Settings on a group apply to every repository beneath it, so an organization sets its defaults
once. An `enforced` setting can't be relaxed further down; the others can be overridden by a
subgroup or a repository.

```terraform
data "gitmoap_group_by_path" "acme" {
  full_path = "acme"
}

locals {
  group_id = data.gitmoap_group_by_path.acme.group_id
}

# Merge requests tidy up their branch, and authors may squash.
resource "gitmoap_group_mr_settings" "acme" {
  group_id                     = local.group_id
  merge_method                 = "merge_commit"
  squash_option                = "allow"
  delete_source_branch_default = true
}

# Nobody approves their own change, and a new push asks for a fresh review.
resource "gitmoap_group_approval_policy" "acme" {
  group_id                = local.group_id
  author_can_approve      = false
  committers_can_approve  = true
  last_pusher_can_approve = false
  reset_on_push           = true
  enforcement             = "enforced"
}

# main changes through merge requests: Developers merge, only Maintainers push directly.
resource "gitmoap_group_branch_rule" "main" {
  group_id         = local.group_id
  branch_pattern   = "main"
  allowed_to_push  = "maintainer"
  allowed_to_merge = "developer"
  allow_force_push = false
}

# Only Maintainers cut release tags.
resource "gitmoap_group_tag_rule" "releases" {
  group_id          = local.group_id
  tag_pattern       = "v*"
  allowed_to_create = "maintainer"
}

# Large files stay out of git history.
resource "gitmoap_group_push_rules" "acme" {
  group_id         = local.group_id
  max_file_size_mb = 50
}

# Forks stay inside the organization.
resource "gitmoap_group_fork_settings" "acme" {
  group_id         = local.group_id
  forking          = "organization"
  forking_enforced = true
}

# New work items are tasks, and a commit saying "Fixes #12" closes #12.
resource "gitmoap_group_issue_settings" "acme" {
  group_id                = local.group_id
  default_issue_type      = "task"
  close_on_commit_keyword = true
}
```

## Schema

### Required

- `group_id` (String) Group ID

### Optional

- `allow_maintainer_edits` (Boolean) Whether the authors of merge requests from forks may let the target's maintainers push to their branch.
- `closed_proposal_retention_days` (String)
- `fork_merge_requests` (String) `disabled`: nobody. `members`: only people who hold a grant on the repository. `everyone`: anyone who can read it.
- `fork_merge_requests_enforced` (Boolean) A group's only: enforce `fork_merge_requests` as a ceiling beneath it.
- `forking` (String) `disabled`: never. `organization`: only into, or towards, the repository's own organization. `anywhere`: any group the person may create repositories in, or any repository of the network. A private repository's `anywhere` is `organization`: private code never forks out of its organization.
- `forking_enforced` (Boolean) A group's only: enforce `forking` as a ceiling beneath it.
- `min_account_age_days` (Number) How old, in days, an account must be to open a merge request from a fork.
- `min_account_age_days_enforced` (Boolean) A group's only: enforce `min_account_age_days` as a floor beneath it.
- `outbound_merge_requests` (String) `disabled`: never. `organization`: only into, or towards, the repository's own organization. `anywhere`: any group the person may create repositories in, or any repository of the network. A private repository's `anywhere` is `organization`: private code never forks out of its organization.
- `outbound_merge_requests_enforced` (Boolean) A group's only: enforce `outbound_merge_requests` as a ceiling beneath it.
- `override_group_settings` (Boolean) For a repository: whether its own row counts.
- `proposal_runs` (String) `approve_each_head`: run nothing until a Developer approves that exact commit. `run_untrusted`: run every such head at once, without secrets — spending the repository's minutes on every contribution.
- `proposal_runs_enforced` (Boolean) A group's only: enforce `proposal_runs` as a ceiling beneath it.
